# Artwork and reference mapping

All six supplied page screenshots are preserved in `references/`. They were used as composition/style references, not embedded as flattened web pages. All headings, navigation, forms and page sections are implemented as HTML/React components.

Fifteen standalone assets were generated using the built-in image-generation tool. The exact prompts are in `image-prompts.json`. Originals are in `design-assets/`; optimized web copies are in `public/images/`. Landscapes are 1672 × 941 pixels. The original logo is a 1254 × 1254 PNG with real transparency; the web logo is trimmed and resized.

These are close generative reconstructions. They cannot guarantee the exact original pixels, faces, buildings, signage or screen content in the supplied mockups. They are illustrative brand scenes, not verified photographs of the company’s premises, staff or clients. The reference’s rendered script words were not baked into new image backgrounds, keeping live text clear and accessible.

The original generated artwork and reference screenshots are retained so the client can replace any recreation with their approved original later. Every image is bundled locally; no third-party image hotlinks are required.
